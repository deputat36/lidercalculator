# Интеграция заявок с сайтом РА «Лидер»

Эта инструкция описывает, как связать сайт рекламного агентства с облачной базой калькулятора.

## Схема

```text
Сайт РА Лидер → форма заявки → таблица leader_leads в Supabase → вкладка «Заявки» в калькуляторе
```

## Что уже подготовлено в базе

Создана таблица `leader_leads` для входящих заявок:

- имя;
- телефон;
- источник;
- сообщение;
- страница сайта;
- статус;
- дополнительные данные.

Публичному посетителю можно только отправить заявку. Просмотр и обработка заявок доступны только после входа в калькулятор.

## Форма для сайта

```html
<form id="leaderLeadForm">
  <input name="name" placeholder="Ваше имя">
  <input name="phone" placeholder="Телефон" required>
  <select name="service">
    <option>Баннер</option>
    <option>Наклейка</option>
    <option>Табличка</option>
    <option>Дизайн</option>
    <option>Монтаж</option>
  </select>
  <textarea name="message" placeholder="Что нужно сделать?"></textarea>
  <input name="website" style="display:none" tabindex="-1" autocomplete="off">
  <button type="submit">Отправить заявку</button>
</form>
<div id="leaderLeadResult"></div>
```

## Логика отправки

В сайт нужно добавить Supabase JS и отправку в таблицу `leader_leads`.

Публичный ключ и адрес проекта уже используются в основном файле `index.html`. Их можно взять оттуда, но секретные ключи использовать нельзя.

## Следующий этап в калькуляторе

- добавить вкладку «Заявки»;
- загрузка заявок из Supabase;
- фильтр по статусам;
- кнопка «Создать заказ из заявки»;
- перевод заявки в статус «Создан заказ»;
- аналитика источников заявок.
