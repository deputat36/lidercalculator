## Что показывает карточка задания

Карточка производственного задания показывает:

- номер связанного заказа;
- название задания;
- статус производства;
- статус макета;
- приоритет;
- срок;
- количество позиций;
- себестоимость;
- ссылку на макет / файл;
- фото места, если оно есть в заказе;
- место размещения / монтаж;
- техническое задание;
- комментарий производству;
- внутренний комментарий;
- состав задания;
- связанные монтажные задания;
- историю производства.

## Что можно редактировать

Из карточки можно изменить:

- название задания;
- статус производства;
- статус макета;
- приоритет;
- срок;
- ссылку на макет / файл;
- техническое задание;
- комментарий производству;
- внутренний комментарий.

После сохранения создаётся событие в `leader_production_events`.

## Печатный лист

Добавлена печать производственного листа.

Печатный лист не содержит:

- имя клиента;
- телефон клиента;
- контакты клиента;
- клиентскую историю.

Печатный лист содержит:

- номер заказа;
- название производственного задания;
- статус;
- срок;
- приоритет;
- место размещения;
- ссылку на макет;
- ссылку на фото места;
- техническое задание;
- состав задания;
- комментарии для производства;
- поля подписи `Передал` и `Принял / выполнил`.
