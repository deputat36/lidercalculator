# Дорожная карта CRM-калькулятора РА «Лидер»

## Уже сделано

- GitHub Pages-репозиторий `deputat36/lidercalculator`.
- Основной файл `index.html` с калькулятором.
- Supabase-база для заказов, позиций, клиентов, проектов, номенклатуры, настроек и резервных копий.
- RLS-политики безопасности.
- Таблица `leader_leads` для заявок с сайта.
- Таблица `leader_user_profiles` для ролей пользователей.
- Таблица `leader_tasks` для задач и напоминаний.
- Таблица `leader_activity_log` для журнала действий.
- Расширение заявок UTM-метками, услугой, бюджетом, предпочтительным способом связи.
- Метрики для будущего дашборда.
