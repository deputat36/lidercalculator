# Форма заявки для сайта РА «Лидер»

Эта инструкция нужна для связки сайта РА «Лидер» с CRM-калькулятором.

## Что уже готово

В Supabase создана таблица `leader_leads`. Она принимает заявки с сайта и хранит:

- имя клиента;
- телефон;
- услугу;
- сообщение;
- страницу, с которой пришла заявка;
- UTM-метки;
- статус заявки;
- бюджет;
- предпочтительный способ связи;
- дату следующего контакта.

## Минимальная форма

```html
<form id="leaderLeadForm">
  <input name="name" placeholder="Ваше имя">
  <input name="phone" placeholder="Телефон" required>

  <select name="service">
    <option>Баннер</option>
    <option>Наклейки</option>
    <option>Табличка</option>
    <option>Печать на плёнке</option>
    <option>Плоттерная резка</option>
    <option>Дизайн</option>
    <option>Монтаж</option>
    <option>Комплексная реклама</option>
  </select>

  <textarea name="message" placeholder="Что нужно сделать?"></textarea>

  <!-- скрытое поле от простых ботов -->
  <input name="website" style="display:none" tabindex="-1" autocomplete="off">

  <button type="submit">Отправить заявку</button>
</form>
<div id="leaderLeadResult"></div>
```

## Что добавить в заявку

При отправке нужно передавать:

- `name`;
- `phone`;
- `service`;
- `message`;
- `source: 'Сайт'`;
- `page_url: location.href`;
- UTM-метки из адресной строки.

## JavaScript-логика

Вариант для старта: отправка напрямую в Supabase через публичный publishable key.

Публичный ключ безопасен только потому, что в базе включены RLS-политики. Публичный посетитель может только добавить заявку, но не может читать заказы, клиентов и прайс.

## Следующий уровень

После проверки формы можно заменить прямую отправку на Supabase Edge Function. Это даст:

- более сильную защиту от спама;
- серверную валидацию;
- email-уведомления;
- возможность отправлять уведомления в другие каналы;
- скрытие логики формы от клиента.

## Статусы заявок

Рекомендуемые статусы:

- Новая;
- В работе;
- Создан заказ;
- Отказ;
- Спам.

## Процесс работы

```text
Клиент оставил заявку на сайте
↓
Заявка появилась в CRM-калькуляторе
↓
Менеджер нажал «В расчёт»
↓
Данные клиента подставились в калькулятор
↓
Сформировано КП
↓
Создан заказ
```
